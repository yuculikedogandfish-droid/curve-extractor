Curve Extractor — Blender 插件 v1.4.19
========================================

配合「Curve Extractor」网页工具使用：网页里提取曲线并导出 JSON，
本插件在 Blender 里生成 3D 曲线和交叉面片。

支持 Blender 3.3 / 3.6 / 4.x（Edit → Preferences → Add-ons → Install）。

一、安装
1. 不要解压后只点 py 文件。请直接安装这个 zip，或安装含本文件夹的 zip。
2. Blender → Edit → Preferences → Add-ons
3. 右上角 Install…（4.2 起可能叫 Install from Disk）
4. 选中 CurveExtractor-v1.4.19-Blender.zip
5. 勾选启用「Curve Extractor」
6. 3D 视图按 N 打开侧栏，找到标签「Curve Extractor」

二、使用
1. 同事用 HTML 工具提取曲线后，点「JSON」，得到 curves.json
   （请用带 3D 的新版 HTML；旧 JSON 只有平面点）
2. 在本面板点「导入 Curve Extractor JSON」
3. 文件对话框里：
   - 缩放：默认 0.01（约 1024 像素 = 10.24 米）
   - Blender Z-up：默认勾选（Blender 常用）。取消则与 UE/OBJ 的 Y-up 一致
   - 可选择是否生成曲线 / 交叉面片
4. 导入后物体在集合 CurveExtractor 里
5. 改面片数量、半宽、夹角后，选中曲线，点「从选中曲线生成面片」可重生成

三、给 UE 的面片
请用 HTML 工具直接导出「面片 FBX」，不要用本插件的网格当 UE 资产源。
本插件面向 Blender 里修曲线、看交叉片、继续做特效。

四、坐标
网页世界：x 向右，y 图像向下，z 深度（侧面）
导入默认转成 Blender Z-up：(x, z, -y)
