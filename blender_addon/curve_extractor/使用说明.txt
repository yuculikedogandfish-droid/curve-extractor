Curve Extractor — Blender 插件 v1.4.26
======================================
内部工具。仅限公司特效使用，禁止外传、禁止上传公网或公开仓库。
图片和提取结果都在本机完成，不要用外网网页上传制作素材。

支持 Blender 3.3 / 3.6 / 4.x。
提取 / 效果 / 导出与网页 v1.4.25 同一套（方向场、去背景、精细模式、三视图、点选补笔、面片 FBX/OBJ/SVG/DXF）。

一、安装
1. 不要只双击 py。请安装这个 zip。
2. Edit → Preferences → Add-ons
3. Install…（4.2 起可能叫 Install from Disk）
4. 选中 CurveExtractor-v1.4.26-Blender.zip
5. 勾选启用「Curve Extractor」
6. 3D 视图按 N，打开侧栏「Curve Extractor」

二、从图片提取（推荐，不经过网页）
1. 点「从图片提取曲线」，选本地光效图或白线黑底线稿
2. 可先调：亮度阈值、色相、饱和度、枝条精细度、分叉着生、走势轴向
   - 精细度：少=主干，多=短枝
   - 着生：少=可悬空，多=贴主枝
   - 轴向：往左=横向环绕光带，往右=竖向根系，中间按长宽自动
   - 精细模式：与网页同一套（精细度 75 / 着生 80）
   - 自动去背景 / 浅色背景自动反色：与网页相同
3. 物体在集合 CurveExtractor 里
4. 默认缩放 0.01（约 1024 像素 = 10.24 米），Blender Z-up

三、三视图
填侧面图、顶面图路径，调「信顶面」（0=侧视准，100=俯视准），勾选「提取前校正」，点「三视图提取」。
线稿会走与网页相同的侧/顶走向匹配 + 深度重建。

四、点选补一笔
填图像像素 X / Y（Y 从上往下），或在图像编辑器里放 2D 游标后点「点选补一笔」。

五、导出（与网页同一套文件）
- JSON：给同事或 Houdini 插件
- 面片 FBX：给 UE（Y-up，含 UV/法线）
- 面片 OBJ
- 线条 OBJ / SVG / DXF：2D 折线（与网页同一套）

六、面片
改数量 / 半宽 / 夹角后，选中曲线，点「从选中曲线生成面片」。
给 UE 的资产请用本插件导出 FBX，不要把插件源码一并外发。

七、注意
- 横幅被截成段：走势轴向往左。
- 等级按原图颜色分组，不按粗细。
- 不要把制作图传到公开 Pages。
